# kmills

I'm not a coder. I started building a few months ago and haven't stopped. This is a working portfolio.

## What I build
Mostly agent systems: several agents that each do one job, with a different one checking the work before anything counts. Some small games. Tools for the stores and sites I run.

## The one habit everything here shares
A check that can't say "I couldn't look" will say "pass." So everything I build is made to say which, and whoever wrote something never grades it.

## Open tools
- [momus-agent-firewall](https://github.com/Themis-Foundry/momus-agent-firewall): checks what a coding agent says it did against what it actually shipped.
- [the-scoreboard](https://github.com/Themis-Foundry/the-scoreboard): measured agent failures from months of real use.
- [agent-guardrails](https://github.com/Themis-Foundry/agent-guardrails): the rules between my agents and my files, each one added after something real broke.
- [pixel-sprite-animator](https://github.com/Themis-Foundry/pixel-sprite-animator): one small sprite in, a whole animated character out.
- [safe-url-fetch](https://github.com/Themis-Foundry/safe-url-fetch): the guard in front of every server-side fetch of an address someone typed.
- [printify-publish-queue](https://github.com/Themis-Foundry/printify-publish-queue): a publish flow that tells a slow listing from a dead one.

Most of what I build stays private. These are the parts worth sharing.
